# v1.0.2

## 中文

### ✨ 概览

`v1.0.2` 主要完善了构建产物分发方式，新增了明确的压缩版与未压缩版输出，方便在生产环境与调试场景之间做清晰选择。

### 🚀 重点更新

- 📦 新增双轨构建产物：
  - `dist/omni-ctx.js`
  - `dist/omni-ctx.min.js`
  - `dist/omni-ctx.global.js`
  - `dist/omni-ctx.global.min.js`
- ⚡ 默认包入口已切换到压缩版 ESM：
  - `dist/omni-ctx.min.js`
- 📝 README 已补充生产环境与调试场景的文件使用说明
- 🧪 构建与包元数据测试已同步更新，确保输出文件、入口映射和文档说明保持一致

### 🧱 构建产物说明

推荐使用方式：

- ⚙️ 生产环境 ESM：
  - `dist/omni-ctx.min.js`
- 🔍 调试环境 ESM：
  - `dist/omni-ctx.js`
- 🌐 生产环境浏览器全局脚本：
  - `dist/omni-ctx.global.min.js`
- 🛠️ 调试环境浏览器全局脚本：
  - `dist/omni-ctx.global.js`

### 📥 安装

```bash
npm install omni-ctx
```

### 📌 说明

- ✅ npm 已发布版本：`1.0.2`
- ℹ️ 这个版本不引入新的运行时 API 变化，主要是构建输出与分发体验优化

## English

### ✨ Overview

`v1.0.2` improves the distribution model by introducing explicit minified and unminified build outputs, making it easier to choose between production-ready bundles and debug-friendly files.

### 🚀 Highlights

- 📦 Added dual build outputs:
  - `dist/omni-ctx.js`
  - `dist/omni-ctx.min.js`
  - `dist/omni-ctx.global.js`
  - `dist/omni-ctx.global.min.js`
- ⚡ Switched the default package entry to the minified ESM bundle:
  - `dist/omni-ctx.min.js`
- 📝 Updated the README with clear production vs debug usage guidance
- 🧪 Expanded build and package metadata tests to keep output files, entry mappings, and documentation aligned

### 🧱 Build Outputs

Recommended usage:

- ⚙️ Production ESM:
  - `dist/omni-ctx.min.js`
- 🔍 Debug ESM:
  - `dist/omni-ctx.js`
- 🌐 Production browser global build:
  - `dist/omni-ctx.global.min.js`
- 🛠️ Debug browser global build:
  - `dist/omni-ctx.global.js`

### 📥 Install

```bash
npm install omni-ctx
```

### 📌 Notes

- ✅ Published npm version: `1.0.2`
- ℹ️ This release does not introduce runtime API changes; it focuses on build output clarity and distribution usability
