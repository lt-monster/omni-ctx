# v1.1.0

## 中文

### ✨ 概览

`v1.1.0` 主要增强了 `context-menu-item` 的图标能力：在保留原有 emoji / 文本 `icon` 属性兼容性的同时，新增了命名插槽图标与单项图标尺寸控制能力，方便接入品牌图标、SVG 与更灵活的菜单视觉设计。

### 🚀 重点更新

- 🧩 `context-menu-item` 现已支持 `slot="icon"`：
  - 可直接传入 `svg`、`img` 或其他自定义节点作为图标内容
- 😀 保留原有 `icon` 属性兼容性：
  - 现有 emoji / 文本图标写法无需修改
- 📏 新增 `icon-size` 属性：
  - 可为单个菜单项单独覆盖图标区域尺寸
- 🎨 图标渲染优先级已明确：
  - 优先使用 `slot="icon"`
  - 未提供插槽时自动回退到 `icon`
  - 两者都没有时自动隐藏图标区域
- 📝 示例页与中英文 README 已更新：
  - 补充自定义 SVG 图标和 `icon-size` 用法示例
- 🧪 已补充测试并完成构建验证：
  - 覆盖源码逻辑、示例页、构建产物与运行时行为

### 🧱 使用示例

```html
<context-menu-item label="Open" icon="📂"></context-menu-item>

<context-menu-item label="Brand Asset" icon-size="18px">
  <svg slot="icon" viewBox="0 0 16 16" aria-hidden="true">
    ...
  </svg>
</context-menu-item>
```

### 📥 安装

```bash
npm install omni-ctx
```

### 📌 说明

- ✅ 发布版本：`1.1.0`
- ℹ️ 本次未扩展程序化 API 的节点型图标传参，动态 `items.icon` 仍保持字符串模式

## English

### ✨ Overview

`v1.1.0` expands the icon capabilities of `context-menu-item`. It keeps the existing emoji / text `icon` attribute fully compatible while adding named icon slots and per-item icon size control, making it easier to use brand assets, SVG icons, and more flexible menu visuals.

### 🚀 Highlights

- 🧩 `context-menu-item` now supports `slot="icon"`:
  - You can pass `svg`, `img`, or other custom nodes as icon content
- 😀 Existing `icon` attribute usage remains compatible:
  - Current emoji / text icon markup continues to work without changes
- 📏 Added the `icon-size` attribute:
  - Override icon box size per menu item
- 🎨 Icon rendering priority is now explicit:
  - Prefer `slot="icon"`
  - Fall back to `icon` when no slotted icon is provided
  - Hide the icon area when neither is present
- 📝 Updated the example page and both READMEs:
  - Added examples for custom SVG icons and `icon-size`
- 🧪 Added tests and verified build outputs:
  - Covers source logic, example usage, build artifacts, and runtime behavior

### 🧱 Example

```html
<context-menu-item label="Open" icon="📂"></context-menu-item>

<context-menu-item label="Brand Asset" icon-size="18px">
  <svg slot="icon" viewBox="0 0 16 16" aria-hidden="true">
    ...
  </svg>
</context-menu-item>
```

### 📥 Install

```bash
npm install omni-ctx
```

### 📌 Notes

- ✅ Release version: `1.1.0`
- ℹ️ This release does not extend programmatic node-based icon input yet; dynamic `items.icon` remains string-based
